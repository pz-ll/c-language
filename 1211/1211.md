# 数组

## 数组

数据类型
- 基本类型（原始类型）：char,short,int,long,long long,float,double,long double
- 复合类型：数组、结构体、联合体、枚举、类
- 指针类型
- void类型

数组：可以存储多个数据值的容器，内存中一块连续的存储空间
存储相同类型的多个元素，依次存储，可以【随机】访问

## 数组的定义

```c
    // 声明：分配空间，默认值随机
    int a[4];       // 4 * 4
    char b[4];      // 1 * 4
    double[6] c;    // 8 * 6

    int n;
    n = 888;
    int m[n];   // 888
    n = 999;

    // 声明 + 赋值 = 初始化
    int a[5] = {1,2,3,4,5};
    int a[5] = {1,2};           0
    int a[] = {100,200,300,400}

```

## 数组的应用

1. 下标从 0 开始，数组作为表，进行数据查询

```c
    int n[4] = {60,70,80,90};
    char level[5] = {'E','D','C','B','A'};

    int s;
    printf("请输入成绩：");
    scanf("%d", &s);

    int i = 0;
    for (; i < 4; i++)
    {
        if (s < n[i])
            break;
    }
    printf("分数：%d, 成绩：%c\n", s, level[i]);
```
